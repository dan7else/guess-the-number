# Guess the Number 🎯

A simple Python game where the computer picks a random number between 1 and 100, and you try to guess it.

## How to play
1. Run the script: `game.py`
2. Enter a number between 0 and 100.
3. The game will tell you if your guess is higher or lower.
4. Try to guess the number in as few attempts as possible.

## Features
- Random number generation
- Input validation (handles non-numeric input)
- Attempt counter
- Hints: "Higher!" / "Lower!"
- Limit check (numbers > 100)

## Requirements
- Python 3.x
